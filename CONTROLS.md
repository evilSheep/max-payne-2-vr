# Controls

| Button | Action |
| --- | --- |
| Left stick | Move |
| L3 | Shoot-dodge / get up |
| Right stick | Turn |
| R3 | Bullet time |
| Triggers \| L2 / R2 | Fire the weapon in that hand |
| Grip buttons \| L1 / R1 | Grab / hold / interact |
| Y / B \| Triangle / Circle | Eject magazine, or reload with Auto Reload enabled |
| Y / B \| Triangle / Circle (holding a grenade) | Switch grenade type with the optional shoulder layout |
| A \| Cross | Jump |
| X \| Square (tap) | Use painkiller when Painkiller Location is set to Button |
| X \| Square (double-tap within 300 ms) | Open / close the game menu, including on death |
| X \| Square (hold for 1 second, alive) | Quick Save; release before saving again |
| X \| Square (hold for 1 second, dead) | Load the latest quicksave; cannot Quick Save while dead |
| Options | Pause / game menu |
| Left Menu \| PS button | SteamVR dashboard; also pauses the game |

Release grip to let go. With toggle grip enabled, press grip again instead.

To talk, face a nearby NPC and reach toward their upper body with an empty,
open hand. No button press is needed. Move your hand away before reaching again
to request another line. Dialogue availability follows the original game scripts.

Quick Save uses the game's normal quicksave slot and save restrictions, preserving
your automatic checkpoint. Holding the button to save does not use a painkiller.
Successful saves show **Game saved** in front of your view for three seconds.

Single-tap painkiller use waits 300 ms to distinguish it from a double-tap.
Double-tapping never uses a painkiller or triggers a save/load.

With **Auto Reload** enabled, an empty gun reloads automatically. The eject button
also starts a reload; the gun cannot fire until the countdown finishes.

The save/load/menu shortcut uses **left A** on Index and **D-pad Down** on Steam
Frame controllers. Dead Man Walking returns to its menu after death.

Two-handed pistol support is enabled by default and can be changed in VR Settings.

## Triggers and fingers

**Trigger Sensitivity** in VR Settings > Weapons & Grips sets how far a trigger
must be pulled to fire, from 20% to 95% of its travel. **Controller Default**
keeps each controller's own firing point. **Disable Finger Movement** in VR
Settings > Body & Scale keeps Max's fingers still: no trigger-finger curl or
pointing, and no finger tracking on empty hands.

## Weapon Wheel (optional)

Turn on **Weapon Wheel** in VR Settings > Inventory. Hold both face buttons on one
hand (**X + Y** or **A + B** | **Square + Triangle** or **Cross + Circle**): a ring of
every gun Max has picked up opens around that hand. Move the hand over a gun and
release to swap the gun in that hand for it; release in the middle to cancel.
This works with an empty hand too: the chosen gun goes into it and stays there
until you squeeze and let go of grip. A
single face-button press still works as usual. **All Weapons** (same menu) gives
Max every gun, grenades and Molotovs with full ammo.

**Steam Frame controllers:** SteamVR's default Frame binding gives the mod the
same button for right B, X and Y, and for left D-pad Up, Left and Right, so the
two-button hold can't work on the left D-pad. Close the game and SteamVR, then
run **Fix Frame Controls.cmd** from the mod download once. After that, right
**B** opens the right hand's wheel and left **D-pad Left** opens the left hand's,
each on its own press; X / Y and D-pad Up / Right still eject, and every other
button is unchanged. Run it again after a SteamVR update if the wheel buttons
stop working. **Restore Frame Controls.cmd** undoes it.

## Stick Actions (optional)

Turn on **Stick Actions** in VR Settings > Turning: right stick up jumps, right
stick down crouches. Right **A | Cross** shoot-dodges when the left stick is pushed,
and starts bullet time when it is centred. With Stick Actions on, hold a stick
click to open that hand's Weapon Wheel.

## Gore

Bullet wounds, blood and dismemberment are on by default. Turn them off with
**Gore** in VR Settings > Body & Scale. Limbs cut off a body can be picked up with
grip and swung like a melee weapon.

## Gun spinning

Hold the eject button (**Y / B | Triangle / Circle**) and release grip: the gun
spins around your trigger finger. Flick your wrist as you let go, or flick a
still, hanging gun forwards or backwards, to start it spinning in that direction;
hand movement keeps it going. Squeeze grip to catch it. Releasing the eject button
while it spins lets go of the gun. Each full turn of the sawed-off loads one shell.
Heavier guns spin more slowly. Turn it off with **Gun Spinning** in VR Settings.
