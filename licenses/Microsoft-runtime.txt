Microsoft C/C++ Runtime

Original C++ binaries use the Visual Studio 2022 runtime through static linkage.
The isolated Python/NumPy runtime includes unmodified application-local release
runtime DLLs. The vcruntime files are sourced from Visual Studio 2022 Community's
VC/Redist/MSVC/14.44.35112/x64/Microsoft.VC143.CRT directory. NumPy's renamed
msvcp140 DLL is retained with the wheel's complete notices.
